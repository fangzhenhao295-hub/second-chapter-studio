# 第二人生 · Second Chapter Studio

面向高校新媒体与地方文化传播的青年视听创作工作室。

## 网站内容

- 高校与地方文化代表案例及完整影片链接。
- 宣传片、专题片、思政教育类影像、活动纪实与新媒体栏目。
- AI 内容创作实践与发展方向。
- 创作团队、制作协作与项目联系方式。

## 发布方式

本网站采用静态 HTML、CSS 与 JavaScript，不需要安装依赖或构建。

GitHub Pages 使用 `main` 分支的根目录发布，网站入口为 `index.html`。

## 文件说明

- `index.html`：网站结构与工作室介绍。
- `studio.css`：响应式样式。
- `studio.js`：轮播、作品筛选、图片预览与联系交互。
- `studio-content.js`：案例与摄影内容。
- `assets/`：网站使用的图片、字体及图标资源。

本仓库只包含第二人生工作室网站，不包含个人作品集备份、参赛文档、身份证件、财务明细或账户凭据。
